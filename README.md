# Pravah

A modern web‑app with a Python backend and a Vite/React frontend, powered by an AI orchestrator.

## Project Structure

- **backend/** – Python server and orchestration logic.
- **frontend/** – React/Vite UI components.

## Setup

1. Install backend dependencies from `backend/requirements.txt`.
2. Install frontend dependencies via `npm install` in the `frontend` folder.
3. Run the backend and frontend as described in the `README` of each subdirectory.
